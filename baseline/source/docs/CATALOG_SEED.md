# Stewardence bounded catalog seed

The version-one seed contains exactly 40 recognizable software and AI product records. It is a matching aid, not a procurement recommendation, security approval, permission claim, retention claim, or representation of current customer use.

All seeded vendors begin with `unverified` / “Review incomplete” status. Exact normalized product-name aliases are accepted as catalog identity aliases. Seeded hostname aliases remain unverified until a catalog reviewer confirms the vendor and product mapping; the matcher will not use an unverified hostname. No provider application ID or OAuth client ID is invented by the seed.

The catalog is deliberately bounded. New aliases require exact evidence and collision review. Unknown inputs remain unknown and enter review; fuzzy similarity and probabilistic AI classification have no authoritative matching role.
