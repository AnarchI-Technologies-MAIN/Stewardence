Evidence boundary

Installation is only an observation

An installed program is not proof of use, a paid subscription, granted permissions, data access, or product capabilities. Stewardence keeps those facts Unknown until specific evidence or a person establishes them.

StewardSensors {{ release.version }}

StewardSensors is delivered as a single Windows executable. Its embedded installation profile is cryptographically signed, and the setup process verifies the sensor executable and module manifest before collection runs. No PowerShell script or execution-policy change is required.
