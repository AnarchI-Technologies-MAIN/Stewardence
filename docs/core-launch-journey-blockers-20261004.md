## Next implementation, in order

1. **Close deliberate capture first.** Add an owner POST with CSRF, current paid/pause/profile admission, user-reviewed scope and a stable retry identity. Capture current active inventory in deterministic order; define whether an empty inventory is explicitly allowed. Add a versioned **benefit model not supplied** contract; do not fabricate hours saved, amortization or monetary values to satisfy the legacy required ROI envelope. Preserve legacy snapshots/readers and qualify downstream proposal, manifest, renderer and comparison handling before offering the path.
2. **Preserve broad audiences and honest applicability.** Non-accounting customers get generic exposure without accounting claims. Accounting/bookkeeping gets its applicable qualified pack. Pin applicability in new snapshots, preserving historical payloads. Accounting-only was a possible mitigation, not an adopted audience restriction.
3. **Make unanswered inventory knowledge explicit.** Introduce explicit unknown/none/declared controls for permissions, data, connected systems, capability and approval; issue declaration provenance only for actual reviewed answers. Include cost unknown handling if absent costs are supported. Regression: omitted checkbox is UNKNOWN; deliberately selected none is a bounded declaration; detected software remains observation, not use/permission approval.
4. **Repair the first-time handoff.** Before capture/freeze, route owners with no immutable WorkflowProfile through deliberate profile selection; retain both supported semantic meanings. After recording it, return to the intended review. Show a useful missing-profile state rather than the generic unavailable response.
5. **Qualify the complete narrow journey.** Fresh signup -> standard test checkout -> verified initial coverage -> workspace/profile -> inventory -> no-benefit capture -> exposure/proposals -> exact owner statement -> freeze -> actual Chromium/private PDF -> history -> cancellation -> expired read/export, with another tenant's negative probes at each private boundary. Then qualify live-mode payment/storage/configuration and restore in an isolated approved environment before final release review. Do not activate gates merely to make the journey appear complete.
